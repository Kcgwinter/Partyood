# Partyood
## What is it
Partyood is a platform for people to give their visitors a possibility to choose what they want to eat.
This will save time and frustration before and while the visit if some people doesn't like what has been chosen. 
It is even possible for hosts to post prices for the food, that they know what to expect if it's a bigger event.
the platform is suppose to be for small to big parties. 

## Why should i use this platform and not just ask my friends what they want to eat
Thats a tricky question to answer because if its just a small batch of friends that is meeting its easy and you know them well. 
But if you organize for example a BBQ for a medium size group of people it gets tricky really fast, some like chicken more some like beef more others prefer Vegetables, 
this is where it all comes together and you don't need to stop at food, you can create drinks yourself too. 
It is an opportunity to help the host having things easier.
